# 论文卡片质量标准

每篇论文读完后，调用 `save_paper_card` 存入 knowledge/。必须满足以下条件。

## 必需

- [ ] 标题 + 作者 + 年份 + 会议/期刊
- [ ] 摘要（可引用原文）
- [ ] 核心贡献（用自己的话写，不抄摘要）
- [ ] 方法概要（做了什么，怎么做的）
- [ ] 在领域地图中的位置（属于哪个子领域，连接了什么）
- [ ] 因果注释（解决了前人什么瓶颈，留下了什么局限）

## 质量

- [ ] 不是摘抄，是理解后的再表达
- [ ] 包含自己的判断（真实价值、可疑之处）
- [ ] 与其他已读论文做了交叉引用

## 可选（但鼓励）

- [ ] 代码是否开源
- [ ] 实验是否可复现
- [ ] 值得 follow 的方向
