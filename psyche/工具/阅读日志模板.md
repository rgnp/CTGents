# 阅读日志模板

每读一篇论文，在 psyche/{领域名}/阅读索引/reading-log.md 中新增一条。

## 格式

```
## [{arxiv_id}] {论文标题}
- **日期**: {YYYY-MM-DD}
- **子领域**: {所属子领域}
- **来源**: {会议/期刊/arxiv}
- **状态**: {已读全文/已读摘要}

### 读前上下文
{我为什么要读这篇？它填补了领域地图的哪个格子？}

### 核心贡献（一句话）
{它做了什么？}

### 因果注释
{它在当时背景下解决了什么前人没解决的问题？有什么隐藏假设？留下了什么新问题？}

### 对 psyche 的影响
{有没有修正之前的认知？有没有新发现或矛盾？}

### 与已有知识的链接
{和其他已读论文的关系：继承/反驳/互补？}

### 可信度评估
{代码开源？数据集多样性？结果可复现？}

### 状态
[已读/需重读/可归档]
```
