# 领域 Psyche 构建协议

> 通用协议，适用于任何领域 psyche 的从零构建。
> 前置步骤：**先走引导流程**（psyche/工具/引导流程.md），对齐范围/用途/深度/约束后再开始。
> 四阶段流程，每个阶段有关口——不过关不推进到下一阶段。

---

## 总则

构建 psyche 不是"写一份文档"，而是"形成一个认知状态"。每篇论文的阅读、每一条因果的建立、每一个判断准则的形成，都是这个认知状态的一部分。

### ⚠️ 知识持久化原则（全流程强制）

1. **双轨构建**：psyche 核心（判断准则）和 knowledge/（原始证据）必须同时构建。核心是索引，知识库是证据层。
2. **可追溯铁律**：核心中的每一条判断，必须有 knowledge/ 中的卡片或笔记作为来源支撑。没有卡片支撑的判断在核心中标为 L3（推理）或 L4（推测），不能标 L1/L2。
3. **先存后炼**：先读原文 → 存卡片 → 再提炼判断。不能跳步。
4. **更新顺序**：更新 psyche 时，先更新 knowledge/ 卡片，再更新核心。核心永远后于知识库。
5. **量变产生质变**：知识库积累到一定量后会涌现新的洞察——不存就没有质变的基础。

## 阶段一：全景测绘

**目标：** 建立领域地图——子领域拓扑、关键时间线、核心团队/会议。

**步骤：**
1. 找到该领域最权威的 2-3 篇综述（看引用量 + 作者背景 + 发表期刊/会议）
2. 每篇综述读全文，不是只读摘要
3. 提取：子领域列表及关系、关键转折点时间线、核心团队/实验室/会议/期刊、综述指出的 open challenges
4. 交叉验证不同综述的结论是否一致，矛盾点记录下来

**产出物：** domain-map.md（psyche/{领域名}/展开/）+ 阅读日志记录

**关口：** 能否不翻资料说清这个领域有几个子领域、它们之间的关系、近3年最大的变化？不能→退回继续读。

## 阶段二：深度浸泡

**目标：** 每个子领域的代表性论文逐篇吃透。

**步骤：**
1. 根据领域地图，每个子领域选代表论文：奠基性工作、转折点工作、最新工作、争议性工作
2. 每篇下载全文，通读
3. 读完后回答三个问题：解决了什么前人没解决的？有什么隐藏假设？留下了什么新问题？
4. **调用 analyze_paper 分析 → save_paper_card 存入 knowledge/{领域名}/（强制）**
5. **每篇文章的阅读笔记也一并存入 knowledge/{领域名}/，不省事只总结**
6. 在阅读索引中记录（含卡片位置字段）

**产出物：** 论文卡片（knowledge/{领域名}/）+ 阅读日志更新（含卡片位置）+ 因果链接记录

**关口：** 能否画出这个领域过去 5 年的技术演进图，标出每个转折点为什么发生？不能→退回补充。

## 阶段三：因果蒸馏

**目标：** 从知识中提炼 psyche 核心认知框架。

**步骤：**
1. 回看所有已读论文，问四个问题：
   - 因果链：真实驱动力是什么？（不是"哪篇论文发了"，而是"什么问题逼着方法进化"）
   - 判断准则：什么样的工作算"好工作"？什么样的 gap 是真 gap？
   - 负面知识：什么东西试过但失败了？为什么？什么条件下会再失败？
   - 边界：共识是什么？争议是什么？根部未解决问题是什么？
2. 撰写核心框架
3. **每条判断显式标注来源（→ knowledge/{领域名}/具体卡片.md）** — 这是强制要求，不是可选项
4. 区分：确认的事实（L1/L2）、推理的结论（L3）、推测（L4）
5. **核心中所有没有卡片支撑的判断，必须标为 L3（推理）或 L4（推测），不能享受 L1/L2 的证据置信度**

**产出物：** core.md + 展开材料 + knowledge-links.md

**关口：** 把这个核心给该领域的研究生看，他会不会觉得"这人真的懂"？不会→退回阶段二补。

## 阶段四：验证迭代

**目标：** 确认 psyche 真正到位。

**步骤：**
1. 基础问题：这个领域现在还有什么好做的？
2. 挑战问题：某个热门方法有什么问题？
3. 边界问题：以单人资源能做什么不能？
4. 对抗问题：如果别人说某个方向有前景，我的独立判断是什么？
5. 每类回答标注：基于确认知识还是推测

**产出物：** 验证记录

**关口：** 以上回答有结构、有分层信心、有来源标注？不能→迭代修正。

## 进化规则

初次构建完成后不是终点。每次对话中：
1. 读到新论文 → 存知识库 → 做卡片
2. 判断：是否改变了认知结构？
3. 如果改变 → 更新 core.md 相关内容
4. 如果值得跨会话记住 → remember
