# Psyche 目录结构说明

> 每个领域 psyche = 一个独立子目录
> 支持父子分层：子 psyche 放在父 psyche 的 sub/ 下，依赖父 psyche 的认知框架

```
psyche/
├── {领域名}/                   # 每个领域一个子目录
│   ├── 索引/{领域名}.md        # name + description + 覆盖范围 + 时效
│   ├── 核心/{领域名}-core.md   # 可注入上下文的认知框架（1-2页浓缩版）
│   ├── 展开/                   # 核心的详细支撑（按需读取）
│   │   ├── domain-map.md       # 领域拓扑 + 时间线
│   │   ├── criteria.md         # 判断准则完整版（可选）
│   │   ├── negative-knowledge.md # 失败经验（可选）
│   │   └── boundaries.md       # 已知边界 + 未读区域（可选）
│   ├── 阅读索引/               # 读了什么、没读什么
│   │   ├── reading-log.md      # 已读论文日志（含因果注释）
│   │   └── reading-gaps.md     # 未覆盖子领域/待读清单
│   ├── 链接/{领域名}-knowledge-links.md  # psyche ↔ 知识库映射
│   └── sub/                    # 子 psyche（分层）
│       └── {子领域名}/         # 结构与父 psyche 相同（索引/核心/展开/阅读索引/链接）
│                                # 但内容只做对父 psyche 的扩展和特化
├── template/                    # 新 psyche 的起点，拷贝过去填
│   └── sub/                    # 子 psyche 模板
└── 工具/                        # 所有 psyche 共享的协议和模板
    ├── 构建协议.md
    ├── 加载协议.md
    ├── 引导流程.md
    ├── 阅读日志模板.md
    ├── 论文卡片质量标准.md
    └── 目录结构说明.md
```

## Psyche ↔ knowledge/ 关系

```
psyche/{领域名}/           ← 认知框架（判断怎么想）
├── 核心/                   ← 浓缩的判断准则（索引层）
├── 展开/                   ← 判断准则的详细展开
└── 链接/                   ← psyche → knowledge 的映射

knowledge/{领域名}/         ← 原始证据（存知道了什么）
├── 论文卡片.md              ← 每篇论文的深度分析
├── 阅读笔记.md              ← 非论文类阅读材料
└── 分析记录.md              ← 跨论文的交叉分析

铁律：核心中的每条判断 → knowledge/ 中有卡片支撑
     没有卡片支撑的判断 ≠ 可追溯
```

## 路径约定

所有内部引用的路径，相对于项目根目录 `D:\project\`。

## 加载规则

- 加载主 psyche 不自动加载子 psyche
- 加载子 psyche 前必须先确认父 psyche 已加载（否则判断准则没有基础）
- 子 psyche 和父 psyche 同时加载时，子 psyche 特化准则优先于父 psyche 的通用准则
