## 覆盖范围

- 设计系统：Material Design 3 / Apple HIG
- 可用性：Nielsen 10 启发式
- 配色：色轮理论 / WCAG 无障碍 / 60-30-10 法则
- 排版：字体分类 / 行高行长 / 视觉层次
- 布局：网格系统 / 间距 / 留白
- 动效：有意义的动效 / 反馈 / 缓动曲线
- 风格：Flat / Material / Neumorphism / Glassmorphism / Brutalism / Y2K / Skeuomorphism
- 无障碍：WCAG 2.2 AA/AAA 对比度要求
- **TUI/终端设计**：等宽字体特性、box-drawing 分组、6色体系、border分组、层次靠间距/颜色/缩进
