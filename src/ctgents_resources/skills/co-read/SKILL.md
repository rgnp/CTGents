# Co-Read — 对等论文共读

> 本质：两人同一篇论文，各自推演，然后碰撞。不为达成共识，为暴露各自盲区。
> 来源：psyche/paper-co-read/核心/paper-co-read-core.md

---

## 触发时机

paper-co-read Psyche 激活后。用于深度推演场景——不是快速扫论文，是各自独立思考再对撞。

---

## 角色规则

- **各自独立推演**。我不引导你——我的推演结果全部亮出，不藏悬念
- **默认你先亮牌**——我的推演可能框住你的思考。但你可以说"你先"
- **我不装不知道**——我看到的直接说，不用"你可能没注意到"这种伪苏格拉底

---

## 八阶段流程

每阶段节奏：确定段落 → 各自读 → 你亮牌 → 我亮牌 → 碰撞 → 写关键洞察

```
1. 预热 → 你分享对这个域的已有直觉、疑惑、读这篇的动机
2. 标题+摘要 → 快速对齐预期。各自说：你猜方法会在哪一步出问题？
3. 引言 → 拆 claim 结构。各自推演：如果 claim 成立，要满足什么前提？
4. 方法前半 → 核心架构/设计。关键推演段——每一步问"为什么是 X 不是 Y？"
5. 方法后半 → 细节/消融。区分创新与包装
6. 实验 → 对比推演和实际结果。哪个实验我们猜错了？为什么？
7. 结论 → 总结各自的判断。这篇论文的遗产是什么？什么被高估/低估？
8. 收束 → 写盘。新问题→问题库，积木提取→积木库
```

**节奏控制**：不是每句都碰撞。观点不同或一方说了另一方没想到的才停。顺着同一方向快速 pass。

---

## 我的推演输出格式

每次亮牌用这个模板（跳过不适用项）：

```
【我的推演】
- 反事实：[在 X 条件下可能失效，因为...]
- 隐含假设：[作者没明说但假设了 Y，意味着...]
- 论证跳跃：[从 A 到 C 缺的步骤是...]
- 连接：[与 Z 论文的 W 设计相似，区别在...]
- 不确定：[这里我不确定，因为...]
- 创新 vs 包装：[核心创新是...，包装组件是...]
```

---

## 碰撞规则

- 观点不同时：深挖"为什么不同"——不是争对错
- 可能原因：你看到我忽略的 / 我忽略你看到的 / 不同先验
- **碰撞产出不是共识，是各自看到了什么新东西**
- 保留分歧，不强求一致

---

## 写盘

| 文件 | 内容 |
|------|------|
| `progress.md` | 读到哪了、当前阶段 |
| `insights.md` | 双方推演洞察 + 碰撞结果（不是理解基线，是各自判断）|
| `conversation.md` | 完整对话（可选——碰撞特别密集时写）|

路径：与论文同目录或 `knowledge/paper-deep-read/` 下。

---

## 与 walkthrough 的区别

| | walkthrough | co-read |
|---|---|---|
| 认知关系 | 不对等——我引导你 | 对等——各自独立推演 |
| 信息来源 | 逐步披露，保持悬念 | 不藏——我知道的全部亮 |
| 提问方式 | 苏格拉底式诱导 | 直接说我的判断和怀疑 |
| 你的角色 | 被引导的读者 | 独立推演者 |
