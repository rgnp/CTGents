# 论文发现协议

只在用户没有提供精确论文路径、标题或 arXiv ID 时读取。

按成本从低到高定位：

1. 搜索已有论文目录的标题、元数据和进行中 walkthrough 状态。
2. 搜索项目内 PDF、论文 Markdown 和文件名。
3. 搜索研究笔记或调研报告中的论文引用。
4. 对最佳候选做标题、作者、年份或 arXiv ID 交叉确认。

零结果时请求论文标题、ID 或文件。多个候选时只呈现最相关的少量候选，并说明区分依据；不要倾倒完整文件列表。

定位后的处理：

- 有正文和 walkthrough：进入恢复协议。
- 有正文无 walkthrough：初始化最小状态，从预热开始。
- 只有 PDF：先转为可读文本。
- 只有引用：取得用户授权或使用现有检索能力获取原文，再开始带读。
