# 带读状态协议

只在跨会话带读、暂停、恢复或完成总结时读取。

## 目录

在论文已有目录下维护：

```text
walkthrough/
  progress.md      # 位置与下一动作
  state.md         # 用户理解快照
  conversation.md  # 仅在确有复盘价值时追加关键对话
  summary.md       # 完成后的用户专属总结
```

## 最小状态

`progress.md` 保存：状态（进行中/暂停/完成）、当前认知阶段、原文位置、下一动作、更新时间。

`state.md` 只保存：

- 已建立的理解基线；
- 用户自己的直觉或异议；
- 已经有效的类比；
- 尚未解决的问题。

不要把完整论文分析或整段聊天复制进 state。`conversation.md` 只记录会影响后续理解的重要碰撞。

## 更新时机

- 进入新阶段：更新 progress。
- 用户形成新直觉、困惑或异议：更新 state。
- 一个未决问题被解决：从未决项移入理解基线。
- 暂停：同步 progress 和 state。
- 完成：标记完成并生成 summary。

## 恢复

1. 读 progress，定位下一动作。
2. 读 state，重建用户理解，而不是复述旧结论。
3. 重新加载论文原文并核对当前位置。
4. 用不超过一小段的摘要说明“读到哪、已经理解什么、还卡在哪里、接下来做什么”。

## 专属总结

完成后的 summary 回答：

- 用户应带走的一句话 insight；
- 论文与用户方向的关系；
- 带读中暴露的核心困惑及论文是否解决；
- 自然生长出的新连接或下一步。
