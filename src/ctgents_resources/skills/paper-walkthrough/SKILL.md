# 论文带读

## 前置条件

- `paper-walkthrough` Psyche 必须已激活；未激活时拒绝执行。
- 本 Skill 不加载 Psyche，也不根据论文关键词自行触发。
- 每次带读都重新取得原文；历史状态只用于恢复用户理解，不能替代原文。

## 开始或恢复

1. 精确定位论文。用户指代不明确时，读取 [论文发现协议](references/paper-discovery.md)。
2. 取得可引用的论文正文和图表；只有 PDF 时先使用项目已有论文解析能力转成可读文本。
3. 若存在进行中的带读状态，读取 [状态协议](references/state-protocol.md)，恢复位置、理解基线、用户直觉和未决问题。
4. 向用户给出一段紧凑恢复摘要，然后从下一个认知节点继续；不要重放完整历史。

## 带读阶段

按理解依赖推进，不机械按章节打卡：

1. **预热**：明确用户为什么读、已有背景和对标题的预期。
2. **问题与主张**：读标题、摘要和引言，建立作者要解决的问题及核心主张。
3. **领域位置**：快速定位相关工作，区分作者叙事与实际差异。
4. **方法直觉**：先沿架构图或输入输出解释核心机制，一次处理一个组件。
5. **方法细节**：直觉成立后再进入公式、训练目标和实现选择。
6. **实验假设**：看结果前先问每个实验试图验证什么、预期应出现什么。
7. **证据与边界**：逐图表核对预期，判断实验支持了多强的主张。
8. **收束**：让用户形成一句话 takeaway、未解决疑问和与自身研究的关系。

深度轴：

- `quick`：保留问题、核心机制和收束，略过大部分细节。
- `standard`：覆盖全部阶段，按用户理解动态调整节奏。
- `close`：逐段推进，记录更多用户推演与跨论文连接。

## 交互规则

- 每次只推进一个认知节点；先引用或转述当前原文，再解释。
- 用户已有清晰判断时与其碰撞，不重复教学。
- 用户卡住时先补参照系或类比，不继续追问。
- 不提前泄露 deep-read 得出的弱点和结论。
- 需要论证审计时，由 owner Psyche 建议在带读完成后切换，不由本 Skill 加载其他 Psyche。

## 暂停与完成

- 发生阶段切换、重要直觉、困惑或新连接时，按状态协议更新轻量状态。
- 暂停时保存当前位置和最小可恢复认知，不复制整段对话。
- 完成时生成用户视角的 takeaway、论文关系、核心疑问及下一步；它不是通用论文摘要。
