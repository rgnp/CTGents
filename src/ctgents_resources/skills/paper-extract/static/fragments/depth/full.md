# full 模式：17 维全面拆解

> 三阶段流水线（评→取→用），全部 17 维。产出分散到知识库各处。

## 阶段一：评 — 审计层

基于 paper-deep-read 结果（不存在时先走 deep-read）。

### D1 论证审计
引用 deep-read card 的核心结论。不重复展开。

### D4 未说出口的
从 deep-read 的"未说出口的"表格中提取 top 3，补充 lite 阶段发现的新缺口。

### D6 前提考古
- 这篇改写了什么前提？（旧前提→新前提）
- 依赖什么未检验假设？
- 这个改写的影响力有多大——如果成立改变了什么？如果不成立呢？

### D9 问题定义审计
引用 lite 阶段的结论。

### D14 知识债务
- 需要补什么前置知识
- 哪些引文需要追读
- 哪些概念需要 learn

### D15 审稿模拟
"如果我是 reviewer——"
- 给什么分（borderline accept / weak reject / ...）
- 最致命的两个问题
- 作者 rebuttal 最怕被问到的问题

---

## 阶段二：取 — 提取层

### D2 积木提取
对每个可复用组件：
- 是什么（一句话 + 核心机制）
- 在什么条件下管用（来自论文消融 + 推断的边界）
- 从哪里抄（前身论文 + 具体参考位置）
- 可复用性评级（★☆）

积木写入 `knowledge/blocks/<component-slug>.md`。

### D3 矛盾定位
和已读论文在前提/方法/结论上的互斥点。不只是「A 说 X，B 说非 X」——
同样重要的是「不同机制相似结果」——这是矿脉。

追加到 `knowledge/domain-maps/contradictions-<domain>.md`。

### D5 实验范式
可复用的 benchmark 组合、metric 选择、消融设计、评测协议。
只在有新模式时追加到 `knowledge/methods/experiment-patterns.md`。

### D7 写作拆解
- 叙事结构
- 命名策略（值得学/不值得学）
- Figure 设计
- 如何制造 urgency
- Limitation 放置策略

追加到 `knowledge/methods/writing-patterns.md`。

### D10 领域坐标
结构化坐标系定位（显式生成←→潜在建模、规划←→仿真）。
这篇往哪个方向推了领域共识。

更新 `knowledge/domain-maps/<domain>.md`。

### D16 差分诊断
同问题不同解法——和最近似方法的逐项对比：
- 共同目标
- 分叉点
- 各自优劣边界
- 调和可能性

---

## 阶段三：用 — 决策层

### D8 复现评估
- 代码开源？模型权重可用？
- 论文描述够不够完整？
- 最大 blocker 是什么？
- 需要什么算力？

### D11 即战力
三级判定：能跑 / 能改 / 能引。每级说清条件。

### D12 用户决策
口头报告，不落文件：
- 方向匹配度
- 单人 A40 可行性
- 最小可发表单元
- 跟的风险
- 不跟的话带走什么

### D13 一句话 takeaway
引用 lite 阶段的结论。

### D17 时间线定位
开端/延续/收尾/孤立。判断依据：作者组历史 + 社区 follow-up + Related Work 引用模式。
