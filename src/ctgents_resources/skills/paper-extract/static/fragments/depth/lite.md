# lite 模式：轻量筛选

> 只走 D1+D4+D9+D13。目标是判断这篇值不值得跟。

## 执行流程

### 1. 前置：确认 deep-read 审计（D1）

如果 paper-deep-read card 不存在 → 先走 paper-deep-read（激活 deep-read Skill）。
如果已存在但超过 2 周 → 复查关键段落确认结论仍然成立。

从已有 deep-read card 提取：
- 核心 claim 和 warrant 最弱一环
- qualifier 的诚实边界
- 实验设计中最不利的比较是否被回避

### 2. 未说出口的（D4）

不重复 deep-read 中已列的——聚焦**新增**的：
- 重读实验表格和 Latency 报告，找没有直接对比的关键 baseline
- 检查所有 ablation——是否在回避某个最关键的消融实验？
- 声称的"优势"背后是否只是更好/更多的训练数据或更大模型？

### 3. 问题定义审计（D9）

回答两个问题：
- 作者自述的问题是什么？
- 从实验设计反推，实际在解决的是什么？（≠ 作者声称的）

判断：这篇是在解决一个科学问题，还是在"加模块、指标涨"？

### 4. 一句话 takeaway（D13）

从用户视角：读完带走什么 insight。（≠ 作者的 claim）

## 判断门

完成以上 4 步后，必须回答：

```
这篇够格切 full 吗？

标准 A: 在用户边界内（latent/occupancy WM，非 VLA/VLM/视频生成/高斯/仿真）
标准 B: 有可提取的积木（不只是指标涨的工程报告）
标准 C: 有可挖掘的矛盾（和已读论文存在值得追问的张力）

三选一 → 切 full。
否则停止，记录为什么不够格。
```
