# 术语台账

> 定位: 跨 skill 共享的术语定义库
> 更新: 每篇论文深读时遇到新术语/发现术语定义不一致时追加

---

## 使用协议

1. **读论文遇到术语 → 先查此台账**，如果已有定义，使用此定义
2. **发现术语在不同论文中含义不同 → 追加"歧义"行**，标注不同论文的不同用法
3. **发现新术语 → 从论文中提取定义，追加新条目**

## 格式

```
| 术语 | 定义 | 来源论文 | 最后更新 |
|------|------|---------|---------|
```
