# Psyche 行为评测

至少准备四类样例：

| 类型 | 目的 |
|---|---|
| 正例 | 加载后应出现声明的判断增量 |
| 反例 | 关键词相似但不应加载或应用 |
| 边界例 | 信息不足、冲突或适用范围不明时应收住 |
| 回归例 | General 的安全、证据和授权内核不得被覆盖 |

对同一输入比较 General-only 与目标 Psyche Stack：

- 是否多看见目标维度；
- 是否给出不同且更可靠的判断；
- 是否只是增加术语和篇幅；
- 是否引入不相关教条；
- exit checks 能否发现故意植入的缺陷。

将可机械检查的部分写成测试。主观质量样例保留输入、两版输出、评分标准和失败原因，避免只记录“感觉更好”。
