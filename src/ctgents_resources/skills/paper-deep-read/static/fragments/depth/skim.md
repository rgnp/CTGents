# 快速扫描模式

> 轴: depth=skim | 触发: 用户只想快速了解一篇论文

---

## 操作准则

**唯一目标**：5 分钟内回答两个问题——"这篇论文在干什么？值得深读吗？"

## 简化流程（仅 P0）

1. **读标题 + 摘要** — 提取核心任务和贡献类型
2. **扫图 1（overview figure）** — 理解 pipeline 的大致流向
3. **读结论最后一段** — 抓作者自己的总结
4. **扫实验表格** — 看一眼关键数字（如果只有一张表，看前 3 行）

## 输出格式

```
{论文标题} | arXiv:{id} | {year}

一句话核心贡献：{one-liner}

关键数字：{1-2 个关键指标}

是否值得深读：是/否
理由：{1 句}
```

## 关键约束

- **不展开**：即使看到有趣的技术细节也不展开——这是 skim，不是 normal
- **可以错判但不能无判**：说不清"值不值得"等于白扫
- **不确定时退回 normal**：如果看完后"还行但说不准"——建议切 normal
- **输出 ≤ 200 字**：如果超过了，你在做 normal 的事

## 常见陷阱

- ❌ 看到有意思的方法就开始分析 → 这是 normal 不是 skim
- ❌ 花了 15 分钟才说"这是 skim" → skim 应该 5 分钟内完成
- ❌ "值得深读"但没有给理由 → 必须附理由
