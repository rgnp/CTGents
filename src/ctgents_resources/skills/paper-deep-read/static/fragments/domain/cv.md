# CV 领域 — 阅读策略

> 轴: domain=cv | 触发: 视觉领域论文

## 领域特有操作

1. **视觉化检查**：论文的 overview figure 是否清晰表达了 pipeline？如果看不懂图 → 论文表达有问题
2. **基准对齐**：用的数据集是否是领域标准（ImageNet/COCO/ADE20K/Waymo/nuScenes 等）？非标准数据集需要额外审视
3. **视觉特有陷阱**：定性结果选择性展示（cherry-picking）、可视化方式不统一、分辨率不一致
4. **向自动驾驶迁移**：如果是 BEV/检测/分割方法，评估能否迁移到自动驾驶场景
