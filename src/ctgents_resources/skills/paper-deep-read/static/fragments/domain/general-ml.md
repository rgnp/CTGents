# 通用 ML 领域 — 阅读策略

> 轴: domain=general-ml | 触发: 不匹配其他特定领域时默认使用

---

## 领域特有操作

### 1. 标准 ML 评估准则

- 实验是否在多个 seed/多次重复上做的？
- 有没有报标准差/置信区间？
- 数据集划分是否合理（train/val/test leak？）
- 超参调优是否对 baseline 公平？

### 2. 通用性检查

- 方法是否只在特定架构/数据集上测试？
- 有没有跨领域/跨任务的泛化实验？
- 论文声称"通用"但只在 1-2 个 benchmark 上验证 → 标为 overclaim

### 3. 领域可迁移性

即使不是自动驾驶论文，也要评估：
- 这个方法/组件能否迁移到自动驾驶场景？
- 如果可以，关键适配点是什么？
- 如果不可以，阻碍是什么？（数据模态不同？任务形式不同？算力需求？）

### 4. 输出

按标准 P5 格式输出，追加"领域可迁移性"一节。
