# 自动驾驶领域 — 阅读策略

> 轴: domain=autonomous-driving | 触发: 论文涉及自动驾驶/轨迹预测/occupancy/世界模型/BEV 等

---

## 领域特有操作

### 1. 五筛子强制过

每篇自动驾驶论文必须过五筛子——不通过的标注风险，不跳过：

| 筛子 | 问题 | 不通过的风险 |
|------|------|------------|
| 算力 | 单人A40（48GB）能跑吗？ | 方法不可复现 |
| 速度 | 推理频率够实时吗（≥10Hz）？ | 上车可行性为零 |
| 开环 | 纯开环评估？闭环也 robust 吗？ | 开环好≠闭环好 |
| L2 | Baseline 是 SOTA 还是随手选的？ | 伪提升 |
| 假设 | 有哪些没说的前提？（全传感器/完美检测/无遮挡） | 现实不可部署 |

### 2. 领域积木定位

每篇论文定位到 `knowledge/autonomous-driving/blocks.md`：
- 这篇论文动的是哪个 block？（感知/预测/规划/端到端/世界模型/生成仿真）
- 和哪个已读论文共享积木？

### 3. 领域特有判断准则

- **轨迹预测**：minADE/minFDE 是否报了对数尺度？多模态是否虚假（所有模态几乎相同）？
- **Occupancy**：是 3D occupancy 还是 BEV occupancy？时序预测还是静态补全？semantic class 的分辨率？
- **世界模型**：是世界模型还是生成式仿真？训练范式（自回归/扩散/GAN）？动作条件是否显式建模？
- **端到端**：是 open-loop IL 还是 closed-loop RL？规划 horizon 多长？

### 4. 算力可行度评估

用户的硬约束：
- GPU: 单卡 A40 48GB 或 RTX 3090/4090 24GB
- 如果论文需求 > 此配置 → 标注"不可复现（算力）"，评估能否缩小规模做
- 如果论文在同等算力下做 → 标注"可复现（算力）"，是 positive signal
