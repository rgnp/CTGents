# 实验研究型论文 — 阅读策略

> 轴: paper_type=research | 适用: 有明确方法-实验-结果链的实证论文

---

## 操作追加

在标准 P0-P5 流程基础上，对实验型论文追加以下检查：

### 1. 方法-实验对齐检查

论文声称的贡献和实验验证之间必须逐条对齐：

| 声称的贡献 | 对应实验 | 对齐？ |
|-----------|---------|-------|
| 更好的性能 | Table 1 主结果 | ✓/✗ |
| 更高效 | FLOPs/time 对比 | ✓/✗ |
| 更好的泛化 | 跨数据集实验 | ✓/✗ |
| 即插即用 | 多 backbone 实验 | ✓/✗ |

任何声称的贡献缺少对应实验 → 标为"unaudited claim"。

### 2. 增量贡献辨识

区分"方法层面的创新"和"工程层面的优化"：
- 方法创新：换了问题建模方式、新的损失函数形式、新的架构设计
- 工程优化：更好的超参调优、更多的数据、更长的训练、更强的 backbone

如果论文的增益主要来自后者，标注为"工程增益为主"。

### 3. 五筛子快速过（自动驾驶论文）

如果 domain=autonomous-driving：
- 单人A40 → 能跑吗？
- <100FPS → 实时性？
- 纯开环 → 闭环也会好吗？
- L2→结果过时 → baseline 是最近的吗？
- 隐式假设 → 有哪些没说出来的前提？

### 4. 复现难度评估

- 代码开源？数据公开？
- 训练 trick 多吗？（多 = 高复现风险）
- 有没有"玄学"组件？（随机种子敏感、需要特殊初始化等）
