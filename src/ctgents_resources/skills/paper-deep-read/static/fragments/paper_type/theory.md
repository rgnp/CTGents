# 理论型论文 — 阅读策略

> 轴: paper_type=theory | 适用: 以数学推导或理论分析为主的论文

---

## 操作追加

理论型论文的论证结构是 proof-based 而非 experiment-based。

### 1. 核心定理/引理识别

- 论文的核心理论贡献是什么定理？（通常 ≤3 个）
- 每个定理回答什么问题？
- 定理的数学形式——能理解到哪个程度？（标注自己理解的天花板）

### 2. 假设审计

理论论文的质量几乎完全取决于假设的质量：

| 假设 | 是否合理？ | 如果放宽会怎样？ |
|-----|----------|---------------|
| ... | ✓/✗/[猜] | ... |

- 哪些假设是标准假设（领域内普遍接受）？
- 哪些假设是"方便推导"（为了证明简化了现实）？
- 如果去掉某个关键假设，结论还成立吗？

### 3. 经验验证检查

- 理论论文有没有经验验证？
- 如果有：实验是不是真的检验了理论的核心主张？还是只是"跑一下看看"？
- 如果没有：是纯粹理论贡献（合理），还是应该验证但没验证（gap）？

### 4. 对实践者的信息提取

用户是实践者。理论论文读到什么程度取决于它能否指导实践：
- 这篇理论能告诉我"什么条件下什么方法会好"吗？
- 有没有 actionable 的 insight？（如"当 X>Y 时用方法 A"）
- 如果纯理论没有 actionable insight，诚实标注"纯理论贡献，暂不用于指导实践"

### 5. 输出增强

P5 卡片追加"假设审计"和"实践指导价值"两节。
