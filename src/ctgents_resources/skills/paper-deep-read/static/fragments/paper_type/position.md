# 立场/观点型论文 — 阅读策略

> 轴: paper_type=position | 适用: 提出新视角、批评现有范式、或倡导新方向的论文

---

## 操作追加

这类论文的价值在"视角"而非"实验"。

### 1. 核心立场提取

- 论文挑战了什么现有共识？
- 它提议用什么替代？
- 它的论证依赖什么证据？（实验引用/逻辑推理/领域趋势分析）

### 2. 论证质量审计

不是审它的实验（它没有），而是审它的论证链：
- 它攻击的"现有范式"是否被公正描述？还是稻草人？
- 它举的反例是否代表性问题还是个例？
- 它的替代方案是否有 concrete 的路线图还是口号式的？

### 3. 建设性不满提取

Position paper 的核心价值在于"建设性不满"（Shannon）：
- 这篇论文对什么不满？
- 这个不满是建设性的吗？（提出了替代方向）
- 这个不满和用户自己的不满有交集吗？

### 4. 对用户的价值

- 这个视角能否启发新的问题方向？
- 如果论文批评的范式恰好是用户在做的方向 → 高价值（自我防御）
- 如果论文倡导的方向正好是用户想做的 → 高价值（找到同盟/引用来论证 motivation）

### 5. 输出（替代 P5 标准格式）

```markdown
# {论文标题} — 立场分析
- 挑战的范式: {what}
- 提议的替代: {what}

## 论证链
{作者的核心推理步骤}

## 稻草人风险
{作者是否公正描述了对手}

## 对用户的启发
- 交集: {和用户方向的关联}
- 可引用的 motivation: {如果有}
```
