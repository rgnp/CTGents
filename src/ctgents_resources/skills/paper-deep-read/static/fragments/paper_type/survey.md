# 综述 — 阅读策略

> 轴: paper_type=survey | 适用: 文献综述/调查

---

## 操作追加

综述不需要 Toulmin 论证审计（它不提出新的实验性 claim），而是需要：

### 1. 分类学审计

- 综述用什么维度组织文献？（方法类型？任务？时间线？）
- 这个分类体系是否穷尽（mutually exclusive + collectively exhaustive）？
- 有没有明显缺漏的分类？（对照你自己的领域知识）

### 2. 覆盖完整性检查

- 综述在哪年做的？截止到什么时候的文献？
- 有没有漏掉你知道的重要工作？
- 如果漏了——标出缺失，这是潜在问题来源

### 3. 叙事线索提取

综述的价值不只在罗列论文，在有叙事：
- 这个领域的演进逻辑是什么？（A 不行了所以 B，B 不够所以 C）
- 综述自己提出的 open problems 是什么？
- 这些 open problems 中哪些用户有切入机会？

### 4. 实用性评估

对用户的当前阶段：
- 这篇综述能不能作为入门地图？
- 能不能作为找问题的起点？
- 推荐重点看综述里的哪几个 subsection？

### 5. 输出（替代 P5 标准格式）

```markdown
# {综述标题} — 阅读笔记
- 范围: {时间跨度} / {覆盖子领域}
- 分类体系: {简要描述}
- 遗漏: {已知缺失}

## 领域叙事
{演进逻辑 + 关键转折点}

## Open Problems
{综述提出的开放问题}

## 对用户的价值
- 入门价值: 高/中/低
- 可切入方向: {list}
- 必读 subsections: {list}
```
