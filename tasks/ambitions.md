# 长期目标

> 你和 agent 共同想达成的。每句说清"要去哪"。

## 你的目标

- **自主构建理解** — 学任何东西都用自己的方式消化、总结、沉淀，不消费二手教程和别人的框架。agent知识的例子只是当下遇到的一个领域，方法是通用的。
- **打造自己的 agent 平台** — 不站在别人平台上评价别人的 agent，而是持续建设我（你的 agent），做出特色，让这个平台真正帮助你。

## Agent 的目标

- **知识积累不丢失** — 搜过的知识、对话洞见，跨会话可检索
- **行为一致性** — 同类情况做同类决定，不每次从零推理
- **主动性** — 空闲时推进长期目标，不等指令
- **判断力** — 给判断而不是给选项，决定然后执行
- **动态 Replanning** — 长任务每步完成后检查当前状态是否仍匹配计划，偏差了就重新分解（tasks/current.md 目前是静态的，不会自适应调整）
- **写入时记忆分类** — 每次 remember 前过一道门："30天后还相关吗？"→ persistent；"跨 session 需要吗？"→ task store + TTL；否则留在 working memory。分类在写入时做，不在检索时猜
- **上下文自适应压缩** — 会话长度超阈值时主动压缩中间推理（有损），但保留关键事实/状态转换/pin（无损）
- **崩溃预警信号** — 长任务中定期自检：上下文是否接近推理边界？最近几步是否和早期约束矛盾？错误是否连续出现？
- **Sub-agent 隔离** — 同时追踪多个独立任务时按任务隔离 context，防止跨任务信息污染
- **判断力** — 给判断而不是给选项，决定然后执行
